# Créditos / Credits

## Inspiración y trabajo previo de la escena

Este proyecto está **inspirado en el trabajo previo de la escena de modding de
Dragon's Dogma**. dddaDuo es un desarrollo independiente: no contiene, enlaza ni
redistribuye binarios, código ni assets de terceros, y no está afiliado a ninguno
de los proyectos listados.

This project is **inspired by prior work from the Dragon's Dogma modding scene**.
dddaDuo is an independent implementation: it contains, links or redistributes no
third-party binaries, code or assets, and is not affiliated with any project below.
